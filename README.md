# SAHAYAK AI (सहायक) 🎙️
### Accessible Hindi and English Voice Assistant Powered by Google Gemini Live

SAHAYAK AI is a real-time, bilingual voice assistant designed for natural, accessible voice communication in **हिन्दी (Hindi)** and **English**. It enables uninterrupted multi-turn voice conversations with instant interruption support, Devanagari typography, robust code-switching understanding (Hinglish), and strict privacy controls.

---

## 🌟 Architectural Highlights

1. **Direct Browser-to-Gemini WebSockets**: Audio streams directly between the browser and Google Gemini Live using constrained short-lived ephemeral tokens generated by `@google/genai`. Vercel serverless functions remain strictly out of the continuous audio path.
2. **Server-Isolated Secret Key**: `GEMINI_API_KEY` is exclusively kept server-side. Ephemeral tokens are minted via `POST /api/live/token` and locked down (`uses: 1`, 60-second connection window, locked model & system instructions).
3. **Supabase Authentication (SSR + PKCE)**: Secure Google OAuth login using official `@supabase/ssr` cookies. Protects the live token endpoint and maintains persistent per-user rate limits.
4. **Natural Bilingual Conversation**: Understands everyday spoken Hindi and English code-switching. Technical English words in a Hindi question do not cause the assistant to switch entirely to English.
5. **Real-Time Interruption**: When the user speaks or presses interrupt, queued audio from the previous turn is immediately discarded and playback ceases instantly.
6. **Hardware Resource Cleanup**: Microphone tracks, AudioContexts, and WebSockets are released immediately upon pressing **End Call**, page navigation, or sign-out.

Before running the application, gather the following credentials:

| Variable Name | Environment | Where to Find / Format | Description |
| :--- | :--- | :--- | :--- |

## 🚀 Quick Start (Local Development)

### 1. Clone & Install Dependencies
```powershell
# In PowerShell (Windows) or terminal
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local`:
```powershell
Copy-Item .env.example .env.local
```
Fill in your credentials in `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
GEMINI_API_KEY=AIzaSyYourSecretGeminiKey
GEMINI_LIVE_MODEL=gemini-2.0-flash-exp
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 3. Run Database Migrations in Supabase
In your [Supabase Dashboard](https://supabase.com/dashboard) &rarr; **SQL Editor**, execute the migration files located in `supabase/migrations/` in numerical order:
1. `001_create_profiles_and_preferences.sql` (Creates `user_preferences` table with RLS)
2. `002_create_conversations.sql` (Creates `conversations` table with RLS)
3. `003_create_transcript_turns.sql` (Creates `transcript_turns` table with cross-tenant isolation constraint)
4. `004_create_token_issuance_limits.sql` (Creates `token_issuance_limits` and atomic rate-limiting function)

### 4. Start Local Development Server
```powershell
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔐 Google OAuth & Supabase Redirect Configuration

> [!IMPORTANT]
> There are **TWO DISTINCT REDIRECT URLs** that must be configured correctly. Misconfiguring these will cause OAuth failures:

### 1. Google Cloud Console &rarr; Supabase Redirect
* **Where**: Google Cloud Console &rarr; APIs & Services &rarr; Credentials &rarr; OAuth 2.0 Client IDs.
* **Field**: **Authorized redirect URIs**
* **Value**: Your Supabase Auth Callback URL:
  ```text
  https://<your-supabase-project-ref>.supabase.co/auth/v1/callback
  ```
  *(Find this in Supabase Dashboard &rarr; Authentication &rarr; Providers &rarr; Google)*
* **Client ID & Client Secret**: Paste Google's Client ID and Client Secret into Supabase Dashboard &rarr; Authentication &rarr; Providers &rarr; Google.

### 2. Supabase &rarr; Application Redirect Allowlist
* **Where**: Supabase Dashboard &rarr; Authentication &rarr; URL Configuration &rarr; **Redirect URLs**.
* **Values**:
  * For Local Dev: `http://localhost:3000/auth/callback`
  * For Production (Vercel): `https://<your-vercel-domain>.vercel.app/auth/callback`

### 3. Google OAuth Consent Screen Test Users (If In Testing Mode)
If your Google Cloud OAuth Consent Screen is in "Testing" publishing status, add your Google test email under:
* Google Cloud Console &rarr; OAuth consent screen &rarr; **Test users** &rarr; **Add Users**.

## 🛠️ Verification & Model Handshake CLI

Test your live credentials and model responsiveness directly from the command line:

```powershell
npm run verify-model
```

This utility performs an end-to-end handshake:
1. Calls `ai.authTokens.create()` via `@google/genai` to generate an ephemeral credential.
2. Establishes a WebSocket connection to `wss://generativelanguage.googleapis.com/.../BidiGenerateContentConstrained`.
3. Sends setup frames for the requested model (`gemini-2.0-flash-exp` or `gemini-3.8-live`).
4. Triggers a spoken greeting and verifies incoming 24kHz 16-bit linear PCM audio buffers.

## 🚢 Deploying to Vercel

1. **Push your code to GitHub**:
   ```powershell
   git init
   git add .
   git commit -m "feat: implement Sahayak AI voice assistant"
   git remote add origin https://github.com/your-username/sahayak-ai.git
   git push -u origin main
   ```
2. **Import Project into Vercel**:
   * Navigate to [Vercel Dashboard](https://vercel.com/new).
   * Select your GitHub repository.
3. **Configure Environment Variables in Vercel**:
   Under **Settings &rarr; Environment Variables**, add:
   * `NEXT_PUBLIC_SUPABASE_URL`
   * `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
   * `GEMINI_API_KEY`
   * `GEMINI_LIVE_MODEL` (`gemini-2.0-flash-exp`)
   * `NEXT_PUBLIC_APP_URL` (`https://<your-project>.vercel.app`)
4. **Update Supabase Redirect URL**:
   * Add `https://<your-project>.vercel.app/auth/callback` to the Supabase Redirect allowlist.
5. **Redeploy**: Click **Redeploy** on Vercel to apply the updated environment settings.

## 🛡️ Privacy & Compliance Notice

- **No Raw Audio Stored**: Voice audio captured from the microphone is streamed directly in memory to Google Gemini Live and is never saved to any database or file system.
- **Transcripts Off by Default**: Conversation transcripts are only stored if the user explicitly turns on the "Save transcripts" toggle.
- **Tenant Isolation**: Row-Level Security (RLS) is enabled on all Supabase tables, ensuring users can only read, modify, or delete their own preferences, conversations, and turns.
